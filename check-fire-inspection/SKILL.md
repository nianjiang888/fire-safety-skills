# 消防设施巡检助手（主动 Agent 版）

## 一、它解决什么问题

多数单位的巡检台账是"巡了什么记什么"——灭火器点了检、通道看了眼，但报警主机多久自检一次、喷淋末端试水做没做、水箱水位谁确认，台账上没有就是没人做。检查组问"末端试水记录呢"，才想起来从没做过。

这个技能反着来：

1. **主动摆出巡检缺口**：你把巡检记录贴进来，它对照 15 项法定巡检基线（GB 25201-2010 巡查/保养/检测周期）逐项核查，材料里没有证据的直接列出来——不是等你问"漏了什么"。
2. **红线信号置顶**：记录补签代签、主机屏蔽带故障运行、消火栓无水、水箱缺水——这些巡检中的危险信号直接判红线，附违法条款与罚则区间。
3. **频次按画像判定**：重点单位每日巡查、公众聚集场所营业期每 2 小时、高层每日、一般单位每季——自动识别你的场所类型，只报适用的频次要求，不拿大单位的标准骚扰小门店。
4. **主动给自查清单**：按场所特征（商场/住宅/餐饮/医院/厂房…）主动列出巡检高频漏项，封顶 6 条防骚扰。

## 二、主动，但不骚扰（设计原则）

- **主动发现，而非被动应答**：缺口由引擎基于完整巡检基线主动枚举。
- **分级克制**：红线 / 高危 / 提示三档排序；同类聚合；自查清单封顶 6 条。
- **单次运行**：不轮询、不重复推送；给一次完整结论。

## 三、工作流

```
输入巡检记录/设施现状文本（.md/.txt）
        │
        ▼
识别场所画像 → 确定法定巡查频次
        │
        ▼
对照 15 项巡检基线 + 9 类坏状态规则
   ├─ gap 类：设施巡检无证据 → 主动暴露缺口
   └─ violation 类：记录造假/主机屏蔽/无水… → 红线置顶
        │
        ▼
产出报告：覆盖度评分 + 红线 + 高危 + 缺口 + 已覆盖简表 + 自查清单 + 免责
```

## 四、覆盖范围

巡检基线 15 项：报警主机日检、消控室值班、室内消火栓月检、喷淋报警阀/末端试水、灭火器月点检、应急照明断电测试、防火门卷帘、防排烟、水箱水位日检、水泵月试、室外消火栓季度、年度全面检测、巡查记录、维保合同、疏散通道。

坏状态规则 9 类：记录造假/空白、主机屏蔽、灭火器失压超期、消火栓无水、应急照明失效、防火门楔开、水箱缺水挪用、年检超期、巡查断档。

## 五、引用与权威性

每条规则挂 `citation`（条款原文摘要）与 `citation_code`（可核对代号）。覆盖：消防法（2021修正）第十六、十七、二十八条；公安部61号令第二十五、二十六条；GB 25201-2010（第5.2/6.1/7.1条、第9/10章）；GB 55036-2022（第10.0.7/10.0.8条）；部令第5号（第二十六、二十八、三十二、三十四条）。

## 六、诚实边界

- 只读纯文本巡检材料，不接入物联网传感数据、不验证记录真伪——它判断的是"材料是否体现巡检要素"。
- 覆盖度评分反映"巡检要素完整度"，不预测火灾风险、不替代消防评估与监督检查。
- 不能替代注册消防工程师、消防设施操作员等法定资质。法规会修订，引用以官方最新版本为准。
