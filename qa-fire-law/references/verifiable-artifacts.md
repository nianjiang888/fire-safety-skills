# 消防法规问答 · 可验证制品

本文件说明这个技能包里有哪些东西是可以自己动手验证的，以及怎么验证。

## 一键核验

```bash
python scripts/smoke_test.py      # 包级冒烟，覆盖三档输入
```

系列级全量复现（引用清单自检 + 输出向量比对 + 出处覆盖率）在 FIre 系列仓库内执行：

```bash
python _foundation/evidence/verify_all.py
```

## 输出向量（可复现）

| 输入 | 随包输出 | 复现方式 |
|---|---|---|
| 提问「消控室能不能单人值班？要什么条件？」 | `examples/sample-qa-single-duty.md` | 包内引擎重跑，逐字节比对 |
| 提问「电动自行车在楼道充电会怎么罚？」 | `examples/sample-qa-ev.md` | 包内引擎重跑，逐字节比对 |
| 提问「小饭店里晚上住人可以吗」 | `examples/sample-qa-threeinone.md` | 包内引擎重跑，逐字节比对 |

引擎为纯规则实现，不含随机与网络调用：给定同一输入，任何机器上得到的报告完全一致。报告日期默认取当天，设置环境变量 `FIRE_GEN_DATE` 可固定为指定日期，便于自动化比对。

## 出处标注

- 规则/知识条目：**22** 条
- 出处标注：**44** 处，命中权威引用清单比例 **100%**
- 本包涉及的权威依据：消防法、公安部61号令、应急管理部令第5号、GB25506、电动车通告、刑法114-115、GB50140、GB25201、GB35181-2025、公消297号、GB26875.10、GB50440

## 边界声明

本技能只做法规条文的结构化整理与主动提示，不替代消防技术服务机构的现场判定，也不构成法律意见。法规修订后以官方最新公布文本为准；地方规定差异较大，具体执行口径以属地消防救援机构意见为准。
