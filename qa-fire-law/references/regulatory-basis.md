# qa-fire-law 权威引用基座（FIre 系列）

> 全部出处为公开现行有效文本，检索核实于 2026-09-06。法规修订后以官方最新公布文本为准。

## 法律

| 条款 | 内容要点 |
|---|---|
| 《中华人民共和国消防法》（2021年修正）第二条 | 消防工作方针（预防为主、防消结合）与原则（政府统一领导、部门依法监管、单位全面负责、公民积极参与） |
| 消防法第五条 | 任何单位和个人都有报告火警的义务 |
| 消防法第十六条 | 单位消防安全职责七项；主要负责人是消防安全责任人 |
| 消防法第十七条 | 消防安全重点单位追加职责（管理人、档案、每日巡查、培训演练） |
| 消防法第十八条 | 多单位共用建筑责任划分；住宅区物业维护管理共用消防设施 |
| 消防法第十九条 | 易燃易爆场所禁与居住同楼；三合一须符合技术标准 |
| 消防法第三十九条 | 专职消防队建立情形 |
| 消防法第四十四条 | 发现火灾立即报警；严禁谎报火警 |
| 消防法第六十条 | 罚则七项（单位 5000-50000 元；个人警告或 500 元以下） |
| 消防法第六十四条 | 过失引起火灾拘留 10-15 日 |
| 《中华人民共和国刑法》第一百一十四条、第一百一十五条 | 失火罪、放火罪刑责 |

## 边界说明

- 本知识库为管理常识口径，不构成法律意见；
- 地方性法规与政策仅收录经核实的示例，具体适用以当地现行文本与消防救援机构意见为准；
- 条款原文以国家法律法规数据库及发布机关官方公布文本为准。
