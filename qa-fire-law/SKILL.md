# 消防法规问答（主动 Agent 版）

问的是大白话，答的是带出处的条款。

## 什么时候用

- 不确定"消控室几个人值班""电动车楼道充电罚多少""店里能不能住人"这类高频问题；
- 想要答案的同时知道**依据哪条**，能拿去跟老板/物业/同事讲清楚；
- 想顺藤摸瓜，看看还有哪些自己没想到的消防合规问题。

## 怎么用

```bash
python scripts/qa.py ask "消控室能不能单人值班？要什么条件？" 回答.md
python scripts/qa.py list      # 看知识库覆盖了哪些主题
```

## 回答里有什么

| 板块 | 内容 |
|---|---|
| 回答 | 简明口径（分条、重点加粗），无术语堆砌 |
| 出处 | 每条答案附权威出处（条款号齐全），核实于 2026-09 |
| 相关问答 | 2-3 条"可能也是你想问的"延伸入口（主动但不骚扰） |
| 兜底 | 未覆盖时：明确承认 + 给最接近主题 + 全主题导航 + 官方渠道建议 |

## 三条铁律

1. **有出处才回答**——22 条知识库条目全部带条款依据；
2. **未覆盖就承认**——匹配不足不硬编，给出主题导航和官方渠道；
3. **回答带延伸**——一次问答附带相关问题入口，帮用户问出该问的。

## 覆盖主题（12 类 22 条）

法律基础 / 责任主体（责任人、物业）/ 单位职责（一般、重点单位）/ 值守要求（消控室值班、单人值班政策）/ 火灾预防（电动车、通道、三合一、动火）/ 罚则与追责（60条罚则、拘留与刑责）/ 设施器材（灭火器配置、年度检测维保、防火巡查）/ 隐患治理（重大火灾隐患判定）/ 智慧消防（297号文、远程监控系统）/ 消防组织（微型消防站）/ 应急处置（报警）/ 能力建设（培训演练）

## 诚实边界（必读）

- 只覆盖内置主题，法规体系庞大（法律/法规/规章/地方立法/技术标准多层），不假装全知；
- 答案为管理常识口径，**不构成法律意见**；地方性政策（如单人值班）以当地现行文本与消防救援机构意见为准；
- 依据核实于 2026-09-06，法规修订后以官方最新公布文本为准。
