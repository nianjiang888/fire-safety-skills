# 火灾分类与灭火方法生成器（FIre 系列 · 主动 Agent 版）

## 一、这个技能做什么

把"火灾分几类、每类用什么灭、怎么灭"这件最容易记混的事，变成一份**带权威出处、可直接转发科普**的简报。

输入是一段自然语言，两种用法都能跑：

1. **泛科普请求**：例如"讲讲火灾分类和灭火方法" → 生成完整的六类划分表 + 灭火四原理 + 常见误区。
2. **具体场景**：例如"厨房油锅着火能用水泼吗""配电柜着火怎么办" → 自动识别火类，先给该场景的处置要点，再附完整分类与原理。

## 二、主动 Agent 定位（主动，但不骚扰）

- **主动识别火类**：你描述"油锅""配电柜""钠"，它直接判定 F/E/D 类并标出对应条款，不用你先懂分类。
- **主动提示最易错的环节**：命中油锅/带电/金属场景时，额外追加"特别提醒"（油锅禁水、带电先断电、金属禁水禁 CO₂），这些正是日常伤亡高发点。
- **主动补齐常识缺口**：即便你只问一类，它也会附上完整六类表，避免"只见树木不见森林"。
- **不骚扰**：单次运行、零追问；误区清单封顶 6 条；无场景时只给科普、不强行制造焦虑。

## 三、权威底座（每条都挂出处，不凭记忆）

- GB/T 4968-2008《火灾分类》（2008-11-04 发布，2009-04-01 实施，代替 1985 版，修改采用 ISO 3941:2007）——六类火灾定义与灭火剂选择。
- GB 50140-2005《建筑灭火器配置设计规范》4.2 灭火器的类型选择——A/B/C/D/E 类选型。
- GB/T 5907.1-2014《消防词汇 第1部分：通用术语》——燃烧三要素与灭火基本原理术语。
- GB 25506-2010《消防控制室通用技术要求》——带电设备管理要求。

包内自包含副本见 `references/regulatory-basis.md`，系列共享引用库见上级 `_foundation/regulations.json`。

## 四、交付物

- `scripts/gen.py`：引擎（纯标准库）。`gen <输入.md> [输出.md]` 生成简报，`version` 看版本，`validate` 自检配方完整性。
- `resources/recipe.json`：六类火灾 / 四原理 / 六误区 / 场景关键词，全部外置可改。
- `examples/`：3 个输入样例 + 3 份真实生成简报（泛科普 / 厨房油锅 / 配电柜带电）。
