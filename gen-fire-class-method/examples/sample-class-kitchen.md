# 火灾分类与灭火方法简报

> 生成依据：GB/T 4968-2008《火灾分类》（2008-11-04 发布，2009-04-01 实施，代替 GB/T 4968-1985，修改采用 ISO 3941:2007）；GB 50140-2005《建筑灭火器配置设计规范》4.2 灭火器的类型选择；GB/T 5907.1-2014《消防词汇 第1部分：通用术语》（燃烧三要素与灭火基本原理术语）；GB 25506-2010《消防控制室通用技术要求》（带电设备管理要求）

## 一、场景识别

根据您描述的内容，主动识别为可能涉及：**F类烹饪物火灾**。
下面先给针对该场景的处置要点，再附完整的分类与原理供您延伸了解。

## 二、针对该场景的处置要点

**F类 烹饪物火灾**
- 典型可燃物：油锅、煎炸油、动植物食用油
- 优先灭火剂：灭火毯、锅盖（隔绝空气）、水基型灭火器、干粉、泡沫、二氧化碳
- 禁用/慎用：水（高温油遇水爆溅、火势扩大）；直接端起燃烧的油锅移动（飞溅烫伤）
- 处置要点：立即关火，用锅盖或灭火毯盖严隔绝空气；勿用水、勿端锅跑；油量大且失控时撤离并报警。
- 依据：GB/T 4968-2008 4.6

## 三、火灾六类划分（GB/T 4968-2008）

| 类别 | 含义 | 典型可燃物 | 适用灭火剂 | 禁用/慎用 |
|---|---|---|---|---|
| **A类** 固体物质火灾 | 固体物质火灾。这种物质通常具有有机物性质，一般在燃烧时能产生灼热的余烬。 | 木材、纸张、棉、毛、麻、塑料、橡胶、织物、家具 | 水（最经济）、泡沫、磷酸铵盐干粉（ABC 干粉）、卤代烷 | 精密仪器、忌水贵重资料宜避免直接用水 |
| **B类** 液体或可熔化固体物质火灾 | 液体或可熔化的固体物质火灾。 | 汽油、柴油、煤油、原油、甲醇、乙醇、丙酮、沥青、石蜡、油漆 | 泡沫（非极性溶剂）、抗溶性泡沫（极性溶剂如酒精、丙酮）、碳酸氢钠干粉（BC 干粉）、磷酸铵盐干粉（ABC 干粉）、二氧化碳、卤代烷 | 水（比重轻于水会浮起扩散、油滴飞溅灼伤）；化学泡沫（极性溶剂 B 类火灾禁用） |
| **C类** 气体火灾 | 气体火灾。 | 煤气、天然气、液化石油气、甲烷、乙烷、丙烷、氢气 | 磷酸铵盐干粉（ABC 干粉）、碳酸氢钠干粉（BC 干粉）、二氧化碳、卤代烷 | 水（无法灭火且可能推动气体扩散） |
| **D类** 金属火灾 | 金属火灾。 | 钾、钠、镁、铝镁合金、钛、锆、锂 | 专用金属火灾干粉（如 7150 灭火剂）、干砂、铸铁屑末、石墨粉、滑石粉 | 水（与活泼金属反应放氢、易爆炸）；二氧化碳（与金属反应、助燃）；普通水基/泡沫（严禁） |
| **E类** 带电火灾 | 物体带电燃烧的火灾。 | 带电的电气设备、配电柜、电缆、电动机、变压器、家用电器、电子元件 | 磷酸铵盐干粉（ABC 干粉）、碳酸氢钠干粉（BC 干粉）、二氧化碳（不得用金属喇叭喷筒）、卤代烷 | 水及水基灭火剂（触电危险）；泡沫（导电）；装有金属喇叭喷筒的二氧化碳灭火器 |
| **F类** 烹饪物火灾 | 烹饪器具内的烹饪物（如动植物油脂）火灾。 | 油锅、煎炸油、动植物食用油 | 灭火毯、锅盖（隔绝空气）、水基型灭火器、干粉、泡沫、二氧化碳 | 水（高温油遇水爆溅、火势扩大）；直接端起燃烧的油锅移动（飞溅烫伤） |

说明：标准将火灾按可燃物类型和燃烧特性分为 A、B、C、D、E、F 六类；ABC 干粉（磷酸铵盐）可扑救除金属（D 类）外的大部分火灾，是日常最通用的选型。

## 四、灭火的四种基本方法

灭火的本质是破坏燃烧三条件（可燃物、助燃物、引火源）之一。四种基本方法：

1. **冷却灭火法**：将可燃物温度降到燃点以下，燃烧即停止。主要用水、二氧化碳等。（常用：水、二氧化碳。依据：燃烧三要素·温度条件（GB/T 5907.1-2014；灭火基本原理））
2. **窒息灭火法**：隔绝或稀释空气中的氧（含氧量低于约 14% 时多数物质难以持续燃烧），使燃烧因缺氧熄灭。用湿棉被、沙土、泡沫覆盖，或充入二氧化碳、氮气等惰性气体。（常用：泡沫、湿棉被/沙土、二氧化碳、氮气。依据：燃烧三要素·助燃物条件（GB/T 5907.1-2014；灭火基本原理））
3. **隔离灭火法**：将可燃物与火源、空气隔开，燃烧因缺少可燃物中止。如搬离火源附近易燃物、关闭阀门切断气/液流、拆除毗连易燃结构。（常用：关阀断料、搬离可燃物、筑堤阻流。依据：燃烧三要素·可燃物条件（GB/T 5907.1-2014；灭火基本原理））
4. **化学抑制灭火法**：灭火剂参与燃烧反应，中断自由基链式反应，使燃烧停止。常用干粉、卤代烷。使用时量要足并配合冷却防复燃。（常用：干粉、卤代烷。依据：燃烧链式反应理论；GB 50140-2005 适用范围）

## 五、常见处置误区（主动提示）

- **油锅/烹饪物着火**：忌“泼水、端起油锅就跑”；应“关火，用锅盖或灭火毯盖严隔绝空气；严禁用水”。（F类，依据 GB/T 4968-2008 4.6）
- **电气设备/配电柜着火**：忌“直接浇水、不拔电就用泡沫”；应“先断电，用干粉或二氧化碳（禁金属喇叭喷筒）灭火”。（E类，依据 GB/T 4968-2008 4.5；GB 25506-2010）
- **钠、钾、镁等金属着火**：忌“用水或二氧化碳扑救”；应“用干砂、石墨粉或专用金属干粉覆盖，严禁用水和二氧化碳”。（D类，依据 GB/T 4968-2008 4.4；GB 50140-2005 4.2.4）
- **燃气泄漏着火**：忌“只顾扑灭火焰不顾气源”；应“在可控前提下先关阀断气；未切断气源前不宜急着灭火以防回火爆炸”。（C类，依据 GB/T 4968-2008 4.3）
- **汽油、酒精等液体着火**：忌“用水直喷”；应“用泡沫（极性溶剂用抗溶泡沫）或干粉、二氧化碳；切断来源”。（B类，依据 GB/T 4968-2008 4.2；GB 50140-2005 4.2.2）
- **用泡沫灭带电设备**：忌“带电状态下用泡沫/水扑救”；应“先断电，或全程使用不导电灭火剂（干粉、二氧化碳）”。（E类，依据 GB/T 4968-2008 4.5）

### 特别提醒

- 厨房油锅着火：**严禁泼水、严禁端锅跑**，关火盖锅盖或灭火毯最有效。
