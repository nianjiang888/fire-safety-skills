# 灭火和应急疏散预案生成器（主动 Agent 版）

## 一、它解决什么问题

消防法第十六条要求每家单位"制定灭火和应急疏散预案、定期组织演练"，但多数单位实际交出来的预案是网上抄的通用模板——组织机构是虚设的、火情预想与本单位重点部位对不上、演练频次不符合法定要求。检查一来就露馅。

这个技能反着来，主动把整份预案摆到你面前：

1. **主动对照法规编制框架**：预案章节按 GB/T 38315-2019（社会单位灭火和应急疏散预案编制及实施导则）逐项落地——单位风险画像、组织机构、火情预想、报警接警、疏散扑救、通讯救护，一章不缺，每章挂出处。
2. **主动按重点部位生成火情预想**：你填"配电室、厨房、车库"，它就生成对应的起火场景与处置要领（电气火灾先断电禁用水、油锅火禁用水用灭火毯、车库电池火灾防复燃）——不是通用套话，是部位级预想。
3. **主动给组织机构人数测算**：按在岗人数算规模系数（<200 人 ×1、200-1000 ×2、>1000 ×3），指挥部、灭火、疏散、救护、通讯、保卫六组人数逐格算清，不是拍脑袋写"若干人"。
4. **主动给容易漏的章节**：微型消防站联动（"3分钟到场"）、演练计划（对照法定频次：重点单位每半年、其他单位每年）、善后复盘与预案年度评审——这三块最常被抄来的模板漏掉，你不问也生成。

## 二、主动，但不骚扰（设计原则）

- **一次输入，整份预案**：填一张 9 字段信息卡（缺项也可跑），产出完整预案书。
- **缺项留白不编造**：没填重点部位就明说"无法生成针对性火情预想"，绝不套用通用场景假装已研判。
- **单次运行**：不轮询、不追问；缺什么在"输入与假设"章节标出来，由你决定何时补。

## 三、输入格式（key: value，中英文冒号均可，缺项可留）

```
单位名称: 某国际中心
建筑类型: 写字楼
建筑面积: 120000 平方米
人员规模: 1800 人
重点部位: 配电室、厨房、数据机房、地下车库
消防设施: 火灾自动报警、喷淋、消火栓、灭火器
现有预案: 有，两年未修订
演练频次: 每年一次
所在省份: 广西 南宁
```

## 五、预案书结构（十一章 + 自查清单）

输入与假设 → 预案定位与法规依据 → 火灾风险画像 → 应急组织机构（规模测算）→ 火情预想（部位级）→ 报警接警与处置流程 → 应急疏散方案 → 初起火灾扑救 → 微型消防站联动 → 演练计划 → 善后与复盘 → 免责声明 → 落地自查清单。

## 七、诚实边界

- 组织机构人数是按规模系数的建议值，最终以单位实际排班与岗位设置为准。
- 火情预想基于重点部位名称匹配标准场景模板；未匹配的部位明确标注"须专项研判"，不硬套。
- 预案是参考文件，不构成法律意见；不替代注册消防工程师、消防设施操作员等法定资质与消防救援机构监督检查。重点单位应委托持证机构审定预案并配合官方演练。
