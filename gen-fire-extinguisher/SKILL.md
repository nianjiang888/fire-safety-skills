# 灭火器配置顾问（gen-fire-extinguisher）

FIre 消防技能系列 #4。回答一个问题：**这个场所该配几具、什么型号、摆在哪。**

## 它解决什么问题

灭火器配置是消防检查里最常开罚单的项目，最常见的三种错法：

1. **数量够、级别不够**——8 具 1A 抵不上表 6.2.1 要求的"单具最低 2A"（中危 A 类场所）；
2. **不知道要打折还是加严**——设了消火栓/喷淋可以按 K=0.9/0.7/0.5 减配（表 7.3.2），但商场、网吧、地下场所反而要乘 1.3（第 7.3.3 条），两者叠加时最容易算错；
3. **摆的位置不达标**——保护距离超了（最不利点取不到灭火器）、箱子上了锁（第 5.1.3 条明令禁止）。

本工具把 GB 50140-2005 的查表计算做成一次透明可复算的方案书。

## 用法

准备一张信息卡（Markdown 或纯文本，`key: value` 一行一项，缺项可跑）：

```
场所名称: 云创科技 6 层写字楼标准层
场所类型: 设有集中空调、复印机的开放式办公室
面积: 600 平方米
火灾种类: A类、E类
危险等级:            ← 可留空，引擎自动判定并给依据
室内消火栓: 无
自动灭火系统: 无
最长对角线: 24 米     ← 可留空，缺省用保护圆近似并提示
现有灭火器: 暂未配置  ← 或填"4具 MFZ/ABC4"做达标核查
```

```bash
python scripts/gen.py gen 信息卡.md 方案书.md    # 生成方案书
python scripts/gen.py version                    # 版本
python scripts/gen.py recipe                     # 配方基数
```

退出码：0 生成成功（含核查达标）；1 现有配置核查不达标；2 参数错误（如缺面积——宁可留白不可错配）。

## 引擎能力

- **自动判定**：火灾五类（A固体/B液体/C气体/D金属/E带电）与危险三级按场所关键词推断，每项判定挂条款依据，且明确"自动判定可修改"——用户显式指定优先；
- **透明计算**：Q = K·S/U（或 1.3·K·S/U），U、K、R 全部带表号条款号，中间值保留两位小数、结果进位取整（第 7.1.1 条）；
- **布点反推**：给了最长对角线按对角线/2R 布点，没给按保护圆覆盖近似并主动提示补齐；
- **逐点清单**：每设置点型号、充装量、单具级别、具数、合计，单具不低于最低配置基准、每点不超过 5 具、单元内不少于 2 具，三重硬约束自动满足；
- **达标核查**：填了现有配置即做数量/单具级别/总级别三重比对，不达标给整改方向（退出码 1）；
- **守住边界**：D 类金属火灾场所按规范"研究确定"口径不出数量，直接转专业设计提示；缺面积不出数。

## 依赖

无。Python 3.8+ 纯标准库。

## 边界（务必阅读）

- 本方案基于自述信息生成，不构成消防设计文件，不能替代施工图审查与消防验收（新建/改建/扩建的配置应作为消防工程设计内容，第 1.0.3 条）；
- 型号与灭火级别为 GB 50140-2005 附录 A 举例，采购以产品铭牌标注为准；
- 危险等级自动判定的责任不在工具——规范以场所实际物质与使用性质为准，判定结果均可人工覆盖；
- 不替代注册消防工程师、消防设施操作员及消防救援机构的检查与判定。
