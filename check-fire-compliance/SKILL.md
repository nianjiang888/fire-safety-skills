# 消防合规体检（主动 Agent 版）

## 一、它解决什么问题

多数消防自检工具是"你给我什么我查什么"的被动模式——你填了材料，它才告诉你哪里不对；你没填，它就安静。这个技能反着来：

**它主动把你没说的缺口摆出来。**

你贴一段单位消防管理现状的描述，它对照一整套法规基线，做三件事：

1. **主动暴露缺口**：哪些法定要求在你材料里没找到任何证据（比如没提消防安全责任人、没提年度检测、没提消控室值班），它不等人问"我漏了什么"，直接列给你。
2. **红线预警前置**：材料里出现设施停用、通道堵塞、消控室无人、灭火器遮挡等明令禁止情形，直接置顶判红线，并标注违法条款与罚则区间。
3. **给可执行的下一步**：每一条缺口/红线后都跟一句该怎么做、依据哪条法规、去哪个标准查。

## 二、主动，但不骚扰（设计原则）

- **主动发现，而非被动应答**：缺口由引擎基于完整基线主动枚举，不依赖用户逐项询问。
- **分级克制**：结果分「红线 / 高危 / 建议」三档，红线必须立即处理，建议项可延后。
- **数量封顶**：优先级行动清单只给 Top 10，同类已聚合，避免一次性甩几十个动作造成认知负担。
- **不骚扰**：它是单次运行工具，不轮询、不重复推送；只在你提供材料时给一次完整结论。

## 三、工作流

```
用户提供一段单位消防管理现状文本（.md/.txt）
        │
        ▼
引擎自动识别单位画像（一般单位 / 重点单位 / 人员密集 / 火灾高危）
        │  画像决定适用规则集
        ▼
对照 27 条法规基线逐一扫描
   ├─ gap 类：命中=已覆盖（内部计分）；未命中=主动暴露缺口
   └─ violation 类：命中=红线预警（置顶）
        │
        ▼
产出报告：覆盖度评分 + 红线预警 + 高危缺口 + 建议 + Top10 行动清单 + 免责声明
```

## 六、诚实边界

- 本技能**只读纯文本**描述，不接入现场传感器、不验证材料真伪——它判断的是"材料是否体现了合规要素"，而非"现场是否真的合规"。
- 覆盖度评分反映"材料中体现的合规要素完整度"，**不预测火灾风险、不替代消防评估**。
- 不能替代注册消防工程师、消防设施操作员等法定资质，也不能替代消防救援机构监督检查。重大场所、重点单位、火灾高危单位应咨询持证机构。
- 法规会修订，引用以官方最新版本为准。
