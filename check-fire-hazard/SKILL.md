# 防火隐患识别（主动 Agent 版）

把"巡了一圈记了几笔"变成"知道哪条违法、会怎么罚、怎么改"。

## 什么时候用

- 巡查记录、自查台账、夜查通报写完之后，想知道里面藏着哪些隐患、严重到什么程度；
- 场所负责人想知道自己描述的现状里，哪些行为已经踩了法规红线；
- 想拿到一份"隐患 → 条款 → 罚则 → 整改动作"四联的处置清单。

## 怎么用（两步）

1. 把巡查记录、自查记录或现场描述存成 `.md` 或 `.txt`（自然语言即可，不用整理格式）；
2. 运行 `python scripts/check.py scan 输入.md 报告.md`，几秒出报告。

## 报告里有什么

| 板块 | 内容 |
|---|---|
| 识别结果 | 命中隐患总数 + 三档统计表（红线/高危/提示） |
| 红线隐患 | 涉嫌违反明文禁令的，置顶：依据（条款号+原文口径）、法定罚则区间、当天可执行的整改动作 |
| 高危隐患 | 重大火灾风险或设施失效，给"本周处置"节奏 |
| 提示项 | 管理性缺陷（巡查缺失、无维保、无培训），纳入例行整改 |
| 主动自查清单 | 描述里没提到、但与场所特征（高层/商场/餐饮/九小/办公/养老医院）强相关的高频隐患点，封顶 6 条 |
| 处置优先级 | Top 8 行动清单，红线置顶 |
| 免责声明 | 见下 |

## 主动但不骚扰，怎么落实的

- 每条隐患只报一次（首个命中词），不重复堆砌；
- 主动清单封顶 6 条，先给场所特征相关的，通用项补齐；
- 处置优先级封顶 Top 8；
- 单次运行出报告即止，不轮询、不追问、不连环提醒。

## 诚实边界（必读）

- 只识别文字描述里的隐患线索，**发现不了没写出来的隐患**，不能替代现场检查；
- 隐患是否构成违法、如何处罚，以消防救援机构认定为准；本工具不构成重大火灾隐患官方判定（那要按 GB 35181-2025 程序走）；
- 无图像识别能力——照片里的隐患请转成文字描述；
- 全部依据为公开现行文本（核实于 2026-09），法律修订后以官方最新公布文本为准。

## 质量与复跑

- 自包含冒烟测试：`python scripts/smoke_test.py`（三档样例 + version，退出码断言）；
- 规则库 22 条，加载期自动校验字段完整、ID 唯一、出处非空。
