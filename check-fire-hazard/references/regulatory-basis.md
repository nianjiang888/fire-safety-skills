# check-fire-hazard 权威引用基座（FIre 系列）

> 全部出处为公开现行有效文本，检索核实于 2026-09-06。引用时保留条款号；法律修订后以官方最新公布文本为准。

## 法律

| 条款 | 内容要点 | 核实来源 |
|---|---|---|
| 《中华人民共和国消防法》（2021年修正）第十六条 | 单位消防安全职责七项：配置消防设施器材并定期检验维修、建筑消防设施每年至少一次全面检测、保障疏散通道/安全出口/消防车通道畅通、组织防火检查、消防演练 | 中国政府网/应急管理部公开文本；海口市养老场所合规指导清单全文引用 |
| 消防法第十七条 | 消防安全重点单位追加职责：消防安全管理人、消防档案、每日防火巡查并建记录、岗前培训与定期演练 | 同上 |
| 消防法第十九条 | 生产、储存、经营易燃易爆危险品场所不得与居住场所同一建筑物；其他"三合一"须符合国家工程建设消防技术标准 | 同上 |
| 消防法第二十八条 | 禁止损坏、挪用、擅自拆除/停用消防设施器材；禁止埋压、圈占、遮挡消火栓、占用防火间距；禁止占用、堵塞、封闭疏散通道、安全出口、消防车通道；人员密集场所门窗不得设影响逃生救援的障碍物 | 贵阳国资"以案普法"（2026-08）、福建住建厅普法专页全文引用 |
| 消防法第六十条 | 罚则：单位违反相关禁令责令改正，处五千元以上五万元以下罚款（七项分列）；个人处警告或五百元以下罚款；拒不改正强制执行、费用由违法行为人承担 | 同上（含多地行政执法事项清单引用） |
| 消防法第六十四条 | 过失引起火灾尚不构成犯罪的，处十日以上十五日以下拘留，可并处五百元以下罚款 | 四川长宁"违规充电引火灾拘留13天"案例普法（2026-04） |

| 部令第5号第二十条 | 电缆井、管道井每层楼板防火封堵；禁止占用或在竖向管井堆放杂物 | 同上 |
| 部令第5号第二十二条 | 禁止在消防车通道、登高操作场地设构筑物、停车泊位、固定隔离桩等障碍物 | 同上 |
| 部令第5号第二十三条 | 餐饮场所灶具与排油烟罩及时清洗，排油烟管道每季度至少检查、清洗一次 | 同上 |
| 部令第5号第二十六条 | 消防控制室24小时值班，每班不少于2名持证值班人员（消防行业特有工种职业资格证书） | 同上；贵阳"以案普法"引用 |
| 部令第5号第二十八条 | 疏散通道、安全出口保持畅通，禁止堆放、锁闭、设障碍物；常闭式防火门保持常闭、闭门器完好；禁止圈占遮挡消火栓、消火栓箱内堆物、防火卷帘下堆物 | 应急管理部官网令文全文 |
| 部令第5号第二十九条 | 禁止占用避难层（间）、避难走道或堆放杂物，禁止锁闭出入口 | 同上 |
| 部令第5号第三十二条 | 不具备自主维保能力的应聘请有资质机构维保检测；停用消防设施须审批、应急方案、防范措施并公告 | 同上 |
| 部令第5号第三十四条 | 高层民用建筑每日防火巡查并填记录；公众聚集场所营业期间至少每2小时一次；医院、养老院、寄宿制学校白天和夜间巡查 | 同上 |
| 部令第5号第三十七条 | 禁止在公共门厅、疏散走道、楼梯间、安全出口停放电动自行车或充电；充电场所应独立设置或防火分隔，充电设施具备充满自动断电功能 | 应急管理部官网令文；央视网（2021-07）解读 |
| 部令第5号第四十七条 | 罚则：动火未审批/未公告/未监护、外墙保温违规、消控室未落实值班、未建消防组织、停用设施未公告、电动车违规停放充电拒不改正等七类，对经营性单位和个人处二千元以上一万元以下罚款，非经营性单位和个人处五百元以上一千元以下罚款 | 应急管理部官网令文；央视网（2021-07）七类行为清单 |
| 公安部《关于规范电动车停放充电加强火灾防范的通告》（2017） | 严禁在建筑内共用走道、楼梯间、安全出口处等公共区域停放电动自行车或充电 | 上海市杨浦区政府普法专页（2026-08）引用 |

## 边界说明

- 本工具识别"文字描述中的隐患线索"，不构成重大火灾隐患的官方判定（那需要消防救援机构按 GB 35181-2025 程序认定）。
- 罚则区间为法定区间，实际处罚由执法机关裁量。
- 场所特征清单（高层/商场/餐饮/九小/办公/养老医院）为管理侧高频隐患归纳，非标准原文条款。
