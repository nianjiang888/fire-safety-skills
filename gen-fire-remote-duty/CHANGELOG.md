## v1.0.1（2026-09-07）

- 新增可验证制品：包内 `references/verifiable-artifacts.md` 说明本包可自行核验的内容（输出向量、核验命令、出处统计、边界声明）。
- README 增加统一的"技术背书与可验证制品"声明块。
- 引擎支持 `FIRE_GEN_DATE` 环境变量：默认取当天，固定该值后可让同一输入在任何机器上产出逐字节一致的报告。
- 引用治理：全系列新增可核验引用清单（28 条，含发布机构、文号、施行日期与公开查证入口），出处标注覆盖率 100%。


- 首个版本，FIre 消防系列 #2（gen 类首包）。
- 主动 Agent 范式：输入 8 字段信息卡，一次生成完整方案书（九章 + 落地自查清单）；缺项标"待补充"不编造；未命中政策库明确留白按双人基线规划。
- 23 地区单人值守政策库（13 省 + 10 市，含条文要点与施行日期，2026-09 检索核实）；广西、山东等条文原文进库。
- 5 条单人值守合规条件逐条核查（地方授权 / 平台远程控制能力 / 监控中心 24h 持证值守 / 设施完好维保 / 人员持证），每条挂出处。
- 人力测算算式透明：三班倒 3×n、四班三运转 4×n，值班长与机动备岗单列，与持证人数自动核对出缺口。
- 主动章节：误报治理机制、断网降级预案（回退双人）——用户未要求也生成。
- 关键出处全部经检索核实：GB 25506-2010（2011-07-01 实施）、公消〔2017〕297号、GB 26875 系列、GB/T 26875.10-2026、GB 50440-2007、T/CFPA 052-2026 等。
- 纯标准库零依赖；免费提供，付费能力预留未启用。
- 冒烟 30/30 PASS（三案例行为自洽 + version + 配方完整性 + 不编造未命中地区政策断言）。
