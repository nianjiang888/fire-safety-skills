# 权威基座与引用说明（check-fire-smart-maturity）

本包所有评分要素与红线判定均挂以下权威出处。检索核实时间：2026-09-06。引用以现行有效文本为准；地方标准仅在本包用于"建设水平参照"，不作为法定强制依据。

## 国家法律

- 《中华人民共和国消防法》（2021 年修正）第十六条：单位应当保障消防设施完好有效，及时消除火灾隐患。——红线 V5 与机制闭环要素 M3 的依据。

## 国家标准

- **GB 50440-2007《城市消防远程监控系统技术规范》**（2008-01-01 实施，第 7.1.1 条为强制性条文）
  - 3.0.2 / 3.0.3：监控中心职责与联网用户范围 → 要素 S1、T4、M4
  - 4.1.2 / 4.1.5：用户信息传输装置设置位置、通信协议符合国家标准 → 要素 T1、T2
  - 4.2.1 / 4.2.2：信息报送时限；同时处理不少于 3 个联网用户火警、接收显示 ≤20s、转发 ≤3s、通信巡检 ≤2h、记录备份 ≥1 年、录音 ≥6 个月、统一时钟 ≤5s → 要素 T3、O1、O2、D51 与红线 V1、V2
  - 4.6.1 / 4.6.2：网络安全（身份认证和授权、防火墙）与应用安全（数据库备份）→ 要素 D52、D53 与红线 V3
  - 第 8 章：系统运行及维护 → 要素 M1
- **GB 26875 系列《城市消防远程监控系统》**（GB 26875.1 用户信息传输装置；GB/T 26875.3 报警传输网络通信协议；GB/T 26875.10-2026 消防设施信息采集装置及接口要求，2026-05-20 发布）→ 要素 T1、T2、T5
- **GB 25506-2010《消防控制室通用技术要求》**（第 4.2.1 条为强制性条文：每日 24 小时专人值班、每班不少于 2 人、持证上岗）→ 红线 V4、要素 O3
- **GB 25201-2010《建筑消防设施的维护管理》** → 要素 M1、红线 V5
- **GB 20517《独立式感烟火灾探测报警器》** → 要素 S6
- **GB/T 22239《信息安全技术 网络安全等级保护基本要求》** → 要素 D53
- **GB/T 28181《公共安全视频监控联网系统信息传输、交换、控制技术要求》** → 要素 S5

## 政策文件

- **公消〔2017〕297号《关于全面推进"智慧消防"建设的指导意见》**（公安部消防局，2017-10-10）
  - （一）建设城市物联网消防远程监控系统"升级版"：监测火灾自动报警运行状态、水压水位、阀门启闭、防火门开关、图像模式识别报警、视频监控安全出口/疏散通道/消控室值班、电气火灾监控（漏电电流、线缆温度）、手机 APP → 维度 D1、D3 主要依据
  - （三）"一张图"实战指挥平台 → 要素 P5
  - （六）加强人才培训 → 要素 M2

## 地方标准与技术规范（建设水平参照，非强制）

- **上海市《消防设施物联网系统技术标准》**：第 6.1.3 条（宜设每日 24h 人工客服值班室）→ 要素 O1 与红线 V1；第 6.2.2 条（数据维护更新机制）→ 要素 D54；第 6.2.4 条（完好率、及时率统计，月度报告与年度评估）→ 要素 P5、M5
- **深圳市《消防设施物联网系统技术要求》（2022-11-01 实施）**：第 7.2.4 条（身份认证、传输加密、数据校验，符合 GB/T 22239）→ 要素 D53；第 8.2.3 条（远程人脸识别、远程应答查岗）→ 要素 O4；第 8.3.3 条（自动巡检生成巡检报告）→ 要素 P3
- **江苏省 DB32/T 4220-2022《消防设施物联网系统技术规范》**：感知层/传输层/数据支撑层/平台服务层分层架构 → 本包六维评估框架的体系参照
- **《消防控制室远程控制管理规范》（征求意见稿）**：第 6.1.6 条（值守人员四级/中级以上资格）、第 6.1.8 条（离岗监管预警）、第 6.1.9 条（音视频交互）→ 要素 O3、O4、O5。**注意：该文件为征求意见稿，未定稿，相关要素仅作建设建议、不作强制判定。**

## 引用规范

每条要素/红线在报告中的"依据"字段 = 文件名 + 条款号，可直接回溯。凡国标未作规定的（如监控中心面积、坐席扩容比例），报告中不作断言；征求意见稿内容一律标注状态。
