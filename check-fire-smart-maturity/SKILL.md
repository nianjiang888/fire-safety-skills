# 智慧消防成熟度评估（check-fire-smart-maturity）

FIre 消防技能系列 #3。评估一个单位的智慧消防建设"建到什么程度了、还缺什么、先补什么"。

## 它解决什么问题

智慧消防建设最常见的三种困境：

1. **不知道缺什么**——装了几台设备、上了个平台，但对照权威基线，感知/传输/平台/值守/数据/机制六个层面各有几项该建的没建；
2. **平台建了没人管**——监控平台无人值守、数据不留痕、账号混用，技防能力名存实亡；
3. **不知道先补哪个**——整改预算有限，需要一条按优先级排好的行动清单。

本技能把"凭感觉汇报"变成一次可复跑的量化体检。

## 用法

```bash
# 评估并输出报告（推荐落盘）
python scripts/check.py scan 我的单位现状.md 报告.md

# 仅打印到屏幕
python scripts/check.py scan 我的情况.txt

# 查看规则基数 / 版本
python scripts/check.py rules
python scripts/check.py version
```

输入：一段用 Markdown 或纯文本写的**智慧消防建设现状自述**（建了什么系统、平台有哪些功能、怎么值守、数据怎么管、有什么制度）。退出码：0 无红线，1 有红线，2 参数错误。

## 评估框架

**六维成熟度**（权重合计 100，30 项要素，每项挂权威出处）：

| 维度 | 权重 | 对应权威基线 |
|---|---|---|
| D1 感知接入 | 20 | 公消〔2017〕297号（一）；GB 50440-2007 |
| D2 传输联网 | 16 | GB 50440-2007 4.1/4.2；GB/T 26875 系列（含 26875.10-2026） |
| D3 平台功能 | 20 | GB 50440-2007；沪/深消防物联网技术标准 |
| D4 值守运营 | 18 | GB 25506-2010 4.2.1（强制）；GB 50440-2007 4.2.2 |
| D5 数据与安全 | 14 | GB 50440-2007 4.2.2/4.6；GB/T 22239 |
| D6 机制闭环 | 12 | 消防法第十六条；GB 50440-2007 第 8 章 |

**成熟度等级**：L1 初始级（0-19）→ L2 起步级（20-39）→ L3 规范级（40-59）→ L4 集成级（60-79）→ L5 智慧级（80-100）。

**五条红线**（命中即置顶预警）：平台无人值守、数据不留痕不备份、平台无认证或账号混用、值守人员无证上岗、监测平台停用瘫痪。

## 主动 Agent 行为约定

- **主动暴露缺口**：材料里没提到的应建要素，逐条列出并挂出处，提醒"可能已建但没写，请对照确认"——不等用户来问；
- **场所自适应**：识别养老/医院/高层/综合体/九小等特征后，主动给出该场所类型的针对性提示；
- **主动但不骚扰**：行动清单封顶 Top 10（红线 > 高优先级缺口 > 中优先级），单次运行出一份报告，不轮询、不追问。

## 依赖

无。Python 3.8+ 纯标准库。

## 边界（务必阅读）

- 基于文本自述评估，无法核实真伪——材料说"已建"就按已建计分，报告不替代现场核查；
- 成熟度等级反映与权威基线的覆盖差距，不预测火灾风险，不构成平台验收结论；
- 地方标准（沪/深/苏）仅作建设水平参照；征求意见稿内容（如值守人员中级资格）标注状态、不作强制判定；
- 不替代注册消防工程师、消防设施操作员及消防救援机构的检查与判定。
